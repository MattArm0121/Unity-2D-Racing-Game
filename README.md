Hello, today in class we worked on making a 2D racing game in Unity. It was our first step touching 2D in Unity and I honestly found it much more preferable than 3D. I think it was just easier for me to manage my work as it's all one surface if that makes sense.

We were then tasked with adding some UI and making the game look good. Such as adding a background and some UI. 

The first thing I did was finish up my track. Earlier in class, we had used these wooden block assets to map it out. So, I continued using those as well as the background asset we were given. I tiled the background asset so I could make it fit the track naturally so it didn't appear stretched.

I also coloured the wooden blocks to make it appear as if it were grass. Now, on second thought, I probably should have found a grass png and used that as my sprite. But then I was worried the collider may not look accurate to how the image was, thus confusing the player. So, I kept it as the wooden block even though it may not match the background. In the future, I could probably make the track be dirt with some grass in the layer in front of the dirt so that way it wouldn't mess with the player's perception of the collider.

Another thing I added, which I had to figure out on my own, was a restart button. Due to my wooden blocks not always being accurate in placement, there was a chance the player could get stuck. Especially on the big hill I intentionally included. So, one press of the restart button restarts the scene for you. Resetting your time and distance.

When you beat the track, there is a little win screen that appears to signal that you have won. Overall, I enjoyed this assignment, getting to add improvements to work in class lets me see how I will think of how to program games in the future. Including fixes to bugs I am spotting on my own.
